# 慧就业公共网站集成需求

## 1. 文档责任

本文是吉林就业公共网站与“慧就业”外部业务系统集成的长期 Requirement fact owner。

本文负责定义：

- 吉林就业公共网站哪些业务区域需要承载慧就业内容；
- 吉林就业业务入口与慧就业页面之间的业务对应关系；
- 当前有效的慧就业完整页面地址；
- 当前使用的业务分类编号和业务编号；
- 吉林就业与慧就业之间需要长期保持的外部集成契约；
- 公共网站技术替换后仍必须保持的产品和集成不变量。

本文不拥有 CMS Domain、CMS 管理能力、前端组件设计、路由实现、CSS、JavaScript 或其他 implementation HOW。

## 2. 产品范围

本需求仅适用于吉林就业公共网站。

当前范围包括：

1. 首页“就业日历”区块；
2. 首页“最新招聘”区块；
3. 首页“直播课程”区块；
4. “招聘信息”及其当前二级栏目页面；
5. “直播课程”二级页面。

本需求不扩展：

- CMS Domain；
- CMS 管理后台；
- CMS API；
- 数据库 Schema；
- 数据迁移；
- 慧就业地址、业务分类编号或业务编号的运营配置能力；
- 慧就业系统自身的内容管理和业务实现。

实现本需求不得以“需要灵活配置”为理由反向增加未经 Requirement Change 授权的 CMS 能力。

## 3. 集成责任边界

吉林就业公共网站负责：

- 吉林就业自身页面框架和导航上下文；
- 首页中承载慧就业内容的业务区域；
- 招聘信息和直播课程的公共网站入口；
- 当前吉林就业栏目状态；
- 慧就业业务页面的嵌入承载；
- 吉林就业业务入口与慧就业目标页面之间的正确对应。

慧就业负责：

- 被嵌入页面内部的业务内容；
- 招聘、职位、双选会、宣讲、直播课程等实时业务数据；
- 被嵌入页面内部的业务交互；
- 慧就业页面自身的运行与内容更新。

吉林就业不重复维护本应由慧就业实时提供的业务内容。

## 4. 集成方式

当前吉林就业与慧就业之间采用**完整业务页面 iframe 嵌入**方式集成。

属于本需求范围的慧就业页面通过 iframe 嵌入吉林就业公共网站指定区域。

iframe 本身属于当前外部系统集成契约的一部分。

具体 iframe DOM 组织、前端组件封装、高度计算、滚动、自适应、加载状态和异常展示方式属于后续 Specification / Technical Design。

## 5. 慧就业页面地址契约

### 5.1 当前地址形态

当前已确认以下慧就业页面地址形态：

```text
https://student.hjiuye.com/calendarEd/2685
```

用于就业日历。

```text
https://student.hjiuye.com/college/2685/{业务分类编号}
```

用于首页某一业务分类的聚合内容。

```text
https://student.hjiuye.com/moreActivities/2685/{业务分类编号}/{业务编号}
```

用于某一业务分类下的具体业务页面。

### 5.2 当前标识

当前集成使用：

- `2685`：当前慧就业集成地址中的固定标识值；
- `4`、`5`：当前使用的业务分类编号；
- `22`、`23`、`24`、`25`、`27`、`30`：当前交付范围内使用的业务编号。

根据现有页面用途可以判断：

- 业务分类编号 `4` 与招聘 / 就业信息相关；
- 业务分类编号 `5` 与直播课程相关。

在获得慧就业正式接口说明、源码定义或其他权威证据前，本文不声明上述文字名称属于慧就业官方编号定义。

但**完整 URL、业务分类编号、业务编号及其业务对应关系均属于当前有效的外部集成契约。**

## 6. 首页就业日历

吉林就业公共网站首页应提供“就业日历”区块。

该区块通过 iframe 嵌入：

```text
https://student.hjiuye.com/calendarEd/2685
```

要求：

- 就业日历在吉林就业首页既定业务区域内呈现；
- 用户无需跳离吉林就业公共网站即可查看和使用相关内容；
- iframe 内部业务内容与交互由慧就业负责；
- 慧就业内容异常不得导致吉林就业首页自身结构整体失效。

## 7. 首页最新招聘

吉林就业公共网站首页应提供独立的“最新招聘”区块。

该区块通过 iframe 嵌入：

```text
https://student.hjiuye.com/college/2685/4
```

要求：

- “最新招聘”应加载上述完整慧就业页面；
- 该区域属于吉林就业首页结构的一部分；
- iframe 内招聘 / 就业信息相关内容及交互由慧就业负责；
- 吉林就业不重复维护与该慧就业页面平行的实时招聘业务内容。

## 8. 首页直播课程

吉林就业公共网站首页应提供独立的“直播课程”区块。

该区块通过 iframe 嵌入：

```text
https://student.hjiuye.com/college/2685/5
```

要求：

- “直播课程”和“最新招聘”属于两个不同的首页业务区域；
- 不得将 `/college/2685/5` 作为“最新招聘”的组成部分；
- iframe 内直播课程业务内容及交互由慧就业负责；
- 首页“直播课程”的“更多”入口应进入吉林就业公共网站自身的直播课程二级页面。

## 9. 招聘信息二级栏目

### 9.1 页面责任

吉林就业公共网站应提供“招聘信息”栏目及以下当前二级栏目：

- 在招职位；
- 招聘简章；
- 双选会；
- 现场宣讲；
- 留省就业。

访问任一二级栏目后，用户应继续处于吉林就业公共网站自身的页面框架和栏目访问上下文中。

页面主体业务区域通过 iframe 嵌入与当前栏目相对应的慧就业完整业务页面。

业务责任关系为：

```text
吉林就业公共网站页面框架
        +
吉林就业当前栏目上下文
        +
慧就业 iframe 业务内容
```

不得出现吉林就业外层显示某一栏目、而慧就业实际加载另一业务内容的情况。

## 10. 直播课程二级页面

首页“直播课程”的“更多”入口应进入吉林就业公共网站自身的直播课程二级页面。

该页面应：

- 保持吉林就业公共网站自身页面框架；
- 保持吉林就业网站导航和访问上下文；
- 在主体业务区域通过 iframe 承载慧就业直播课程业务页面。

当前完整地址为：

```text
https://student.hjiuye.com/moreActivities/2685/5/27
```

当前集成契约为：

## 12. 页面与业务一致性

公共网站必须保证：

- “就业日历”加载就业日历对应的慧就业页面；
- “最新招聘”加载最新招聘对应的慧就业页面；
- “直播课程”加载直播课程对应的慧就业页面；
- 招聘信息当前二级栏目与 iframe 内实际业务内容一致；
- 直播课程“更多”入口进入的二级页面与其 iframe 业务内容一致。

吉林就业外层业务名称、导航状态和页面语义不得与慧就业实际加载内容产生错位。

## 13. 外部系统异常边界

慧就业属于吉林就业公共网站之外的外部业务系统。

当慧就业页面无法连接、加载失败、请求超时或暂时不可用时，吉林就业自身的 Header、导航、Footer、当前栏目上下文和页面其他非慧就业内容不得因此整体失效。

公共网站应能够区分“吉林就业页面本身不存在或异常”和“吉林就业页面正常，但慧就业外部内容暂不可用”。

具体 loading、timeout、fallback、retry 和错误提示表现由后续 Specification 定义。

## 14. 技术替换不变量

本需求不规定：

- Frontend framework；
- Router 实现；
- Vue component；
- `rendererKey`；
- Site Definition 物理字段；
- iframe component 的组织方式；
- iframe 高度与滚动实现；
- CSS / JavaScript 方案。

公共网站技术实现发生替换时，以下要求仍必须成立：

1. 首页就业日历、最新招聘、直播课程三个集成区域继续存在；
2. 三个首页区域继续加载本文规定的完整慧就业地址；
3. 招聘信息五个当前二级栏目继续保持本文规定的业务映射；
4. 直播课程二级页面继续对应业务分类编号 `5`、业务编号 `27`；
5. 吉林就业业务入口与慧就业实际业务内容保持一致；
6. 吉林就业页面框架与慧就业内部业务责任保持分离；
7. CMS 产品边界不因为前端实现替换而扩大。

## 15. 当前验收不变量

当前实现至少必须能够证明：

1. 首页就业日历实际嵌入 `https://student.hjiuye.com/calendarEd/2685`；
2. 首页最新招聘实际嵌入 `https://student.hjiuye.com/college/2685/4`；
3. 首页直播课程实际嵌入 `https://student.hjiuye.com/college/2685/5`；
4. 在招职位实际对应 `https://student.hjiuye.com/moreActivities/2685/4/22`；
5. 招聘简章实际对应 `https://student.hjiuye.com/moreActivities/2685/4/23`；
6. 双选会实际对应 `https://student.hjiuye.com/moreActivities/2685/4/24`；
7. 现场宣讲实际对应 `https://student.hjiuye.com/moreActivities/2685/4/25`；
8. 留省就业实际对应 `https://student.hjiuye.com/moreActivities/2685/4/30`；
9. 首页“直播课程”的“更多”入口能够进入直播课程二级页面，并实际嵌入 `https://student.hjiuye.com/moreActivities/2685/5/27`；
10. 吉林就业外层业务状态与实际嵌入的慧就业业务内容不存在错位；
11. 慧就业外部页面异常不会破坏吉林就业自身页面框架；
12. 本功能没有因此新增或改变 CMS 产品能力。

## 16. 非决策

本文不决定：

- 是否复用一个或多个 iframe 组件；
- 页面和组件源码目录；
- 新站是否使用类似旧站 `activeNum` 的参数；
- 招聘信息不同二级栏目采用同一页面实现还是多个页面实现；
- iframe 高度、自适应、滚动和移动端技术方案；
- iframe loading / timeout 的具体阈值；
- 前端如何组织或生成上述目标地址；
- 自动化测试框架与具体测试代码。

原网站的页面文件名、Query Parameter 和 JavaScript 处理逻辑属于需求来源证据，不构成新公共网站必须继承的实现约束。
