# CMS 管理身份、授权与操作审计需求

## 1. 责任与阶段

本文拥有 CMS 管理访问的长期 Product / Domain 事实：可信操作人、CMS 角色、管理操作授权、操作审计及独立部署和外部管理平台集成的共同边界。当前 Server 已建立统一管理主体、Admin 请求 / 方法授权、管理写操作审计产生和持久化，并提供 `super` 专属的有界审计查询；正式身份提供方和全局管理端身份反馈仍未完成，因此当前能力不等同于生产登录闭环。隔离 Review 环境还需要为测试人员提供可操作的模拟身份入口，使未认证、`admin`、`super`、禁止访问、退出和身份失效能够在真实 Browser / Runtime 中复核。

本文不规定安全框架、AOP 注解、数据库表、登录协议、界面组件或具体推进顺序。管理端可观察行为由对应 Specification 持有，结构与技术选择由 Architecture / Technical 持有。

## 2. 目标与身份边界

CMS 必须能够在独立网站部署和接入外部管理平台时，依据一个经过可信验证的管理主体执行相同的业务授权与操作审计。

第一版的管理主体只要求：

- `identitySource`：身份来源的稳定标识；
- `userId`：该来源内稳定、不可被重新分配给其他人的用户标识；
- `roles`：经受信规则转换后的 CMS 角色集合。

`identitySource + userId` 共同标识操作人；单独的显示名、手机号、部门、用户详情和 CMS 本地用户记录不是第一版的授权或审计前提。当前阶段不建设 CMS 用户管理、密码管理或角色分配界面。需要展示用户详情时，可另行定义可选查询能力，不得改变已有审计身份。

CMS 不接受客户端自行声明的用户 ID 或角色作为可信主体。身份来源必须验证凭证，且角色转换必须由受信配置或服务控制；未知、无效或无允许角色的主体不能进入管理能力。测试身份只可用于隔离的开发、自动化测试和人工评审环境，不能成为正式部署的登录方式。隔离 Review 环境可以提供测试人员可操作的模拟身份入口，但该入口只选择由 Server 控制的预置测试主体，不建设 CMS 本地账号库、密码登录、角色分配或用户管理；正式 Server 产物不能包含可启用的测试认证端点、测试验证器或默认测试主体。

## 3. 角色与权限

第一版只定义两个 CMS 角色：

| 角色 | 当前权限范围 |
|---|---|
| `admin` | 当前 CMS 的全部日常业务管理操作，包括内容、发布、结构、展示、站点属性和资源维护 |
| `super` | 包含 `admin` 的全部业务权限，并可查看 CMS 操作审计记录 |

没有当前业务能力对应的安全管理操作，不得为了区分角色而凭空增加。以后新增细化角色时，只增加当前业务操作的部分权限，不缩减第一版 `admin` 的业务权限或 `super` 的覆盖范围；新增能力的授权另行确认。

授权必须在 CMS 服务端对管理 API 的真实操作生效。管理端菜单或按钮可反映授权结果，但不能代替服务端校验。无身份、无允许角色或访问超出权限时必须拒绝，不能回退到公开访问或默认管理员。现有业务不变量，包括 preset protection、来源身份限制、发布前置条件和资源安全，对 `super` 同样适用。

第一版不引入按栏目、Main / Party、组织、租户或个人数据范围的授权；实际出现隔离需求时另行确认 Domain 和数据访问契约。

## 4. 操作审计

CMS 管理端的业务写操作必须形成可追溯记录。每条记录至少包含：身份来源、用户 ID、操作时的 CMS 角色、业务动作、对象类型及可用的对象标识、时间、结果和请求关联标识。成功记录必须对应实际提交的业务结果；失败或回滚不能记为成功。

第一版不记录用户详情、完整正文、密码、令牌或其他凭证。历史审计以操作时保存的身份与角色为准，不用用户当前角色改写历史。审计查询仅授予 `super`。审计记录不随业务对象普通删除而消失，不由普通 CMS 写接口修改。

普通运行日志、安全事件日志与业务操作审计具有不同职责；一次请求可以关联，但不能以 HTTP access log 代替业务审计。具体保留期限、导出格式及外部审计平台对接属于后续独立要求，不在第一版预设。

## 5. 部署边界与非目标

接入智慧就业平台或其他管理后台时，外部系统负责自己的登录及用户生命周期，CMS 只消费经验证并转换的身份。独立网站正式部署也必须配置真实可信的身份来源；仅有测试模拟登录不构成可上线的独立管理系统。

第一版不包含 CMS 本地账号库、用户资料同步、密码登录、用户管理 UI、外部角色表共享、多级审核、任意多租户或完整 SSO 平台建设。具体身份协议在目标宿主确定后选择，不从若依、JEECG 等示例推定平台实现。
