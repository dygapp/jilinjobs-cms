# 信息发布与网站服务需求

## 1. 文档目的

本文用于明确吉林省智慧就业云平台信息发布与网站服务的建设目标、网站组成、栏目结构、前台展示、后台内容管理、外部内容集成、历史内容迁移和非功能边界，作为后续原型设计、功能设计、开发、测试及验收的业务依据。

项目背景、总体范围和公共技术基线以[智慧就业云平台系统改造项目基准信息](../../../project/project.md)最新版为准；模块划分及跨模块职责以[业务能力地图与模块边界基线](../../overview/system-module-boundaries.md)最新版为准。

本文是一份承载两个 L2 的综合需求文档：

| L2 | 核心职责 | 本文主要章节 |
|---|---|---|
| L2-28 网站内容管理与发布 | 维护栏目、内容、发布状态、首页运营内容、服务入口、网站导航和站点公共信息 | 用户与后台权限、栏目建设、内容管理、首页与展示内容管理、历史内容迁移 |
| L2-29 网站展示与服务导航 | 面向社会公众提供主站和中心党建展示、公开内容浏览与分享、第三方嵌入及外部服务导航 | 网站总体组成、前台功能、第三方内容集成、视觉交互、公开访问与服务跳转 |

两个 L2 通过“后台形成已发布内容，前台只读消费”建立依赖。后台内容对象与前台展示方式保持边界，不因当前共用一份文档、一个网站或一套后台而合并为单一 L2。

## 2. 建设背景与目标

信息发布与网站服务对应“吉林省高等学校毕业生就业信息网”。现网站公开入口为 `www.jilinjobs.cn`，访问后可跳转至实际运行域名；原入口和实际运行域名均代表同一网站。

第一阶段按照“现网功能复刻、内容管理重建、外部能力继续集成、双主题呈现、适度现代化改造”的原则完成网站重新开发，主要目标如下：

1. 保持现有网站的主要栏目、信息结构和公开服务入口；
2. 完整重建本站内容发布与后台管理能力；
3. 保留主站蓝—青色主题和“中心党建”红色主题的差异化呈现；
4. 继续集成慧就业等第三方招聘服务，不重复建设外部业务功能；
5. 完成现网站自有文字、图片和附件等内容的整体迁移；
6. 提升移动端适配、浏览器兼容性和内容可访问性，满足公开内容基础搜索引擎收录需要；
7. 基于定稿需求建设高保真前台原型，用于确认视觉框架和信息结构。

## 3. 范围与边界

### 3.1 建设范围

第一阶段包括：

- 网站公开前台；
- 主站首页及公共内容页面；
- “中心党建”独立栏目、栏目首页及红色主题页面；
- 栏目、文章、单篇内容、外部链接、图片入口和嵌入内容管理；
- 轮播图、专题横幅、快捷入口、首页推荐位和网站导航管理；
- 站点公共信息管理；
- 文章图片和附件管理；
- 内容浏览量记录；
- 统一后台账号、角色、菜单及栏目权限接入；
- 现网站自有内容迁移和可识别历史地址兼容；
- 主流桌面端和移动端响应式适配；
- 高保真前台原型。

### 3.2 不在第一阶段建设的内容

第一阶段不包括：

- 招聘职位、招聘简章、双选会、宣讲会和直播课程等第三方业务功能重建；
- 微信公众号自身的内容发布和菜单管理；
- 网站前台注册、登录、个人中心及身份认证；
- 文章评论、点赞、收藏、用户投稿、在线留言、在线咨询和工单；
- 多级内容审核流程；
- 站内全文搜索；
- 独立公共素材库；
- 通用可视化页面设计器；
- 第三方嵌入内容缓存、同步和故障重试；
- 复杂网站流量分析、用户画像、访问来源分析和统计报表；
- 复杂搜索引擎优化、关键词运营和收录效果分析；
- Internet Explorer 兼容；
- 完整后台高保真原型。

## 4. 网站总体组成

### 4.1 主站

主站承担就业信息、政策法规、业务指南、典型事迹、招聘服务入口和机构信息等内容的统一公开展示，整体延续蓝色、青色为主的视觉风格。

### 4.2 中心党建

“中心党建”是主站中的独立一级栏目，包含独立栏目首页和子栏目，并使用红色党建主题。其内容呈现相对独立，但不作为技术上独立部署的子网站：

- 与主站共用一套接口服务；
- 与主站共用一套后台管理；
- 复用统一账号、权限和内容模型；
- 可以独立配置主题横幅、栏目首页和推荐内容；
- 使用独立的红色主题首页、列表页和详情页样式；
- 共享必要的全局导航、公共版式和页脚信息。

### 4.3 外部内容

招聘日历、招聘信息、直播课程等内容继续由慧就业等外部平台提供。网站展示与服务导航只负责：

- 配置嵌入地址和展示入口；
- 在本站页面框架中呈现第三方内容；
- 提供加载异常提示和原页面访问入口；
- 在移动端无法合理适配时改为外部链接入口。

外部内容的数据维护、业务处理、用户认证、可用性和自身浏览器兼容性不属于本子系统责任。

## 5. L2-28 与 L2-29 的用户和权限

### 5.1 前台访问用户

网站公开内容面向互联网用户，无需注册或登录。学生业务入口、就业信息填报等功能只负责跳转到智慧就业云平台或其他目标系统，身份认证和业务办理由目标系统负责。

### 5.2 后台用户

后台只面向：

- 具有固定中心系统管理员角色的用户；
- 获得相应菜单或功能入口的中心业务人员。

学校、学院和学生不参与网站内容维护。

### 5.3 后台权限

后台复用智慧就业云平台统一账号、角色和菜单权限体系，可分别控制：

- 栏目管理；
- 内容编辑；
- 内容发布与撤回；
- 首页内容和推荐位管理；
- 站点配置。

栏目权限用于限制用户可维护的内容范围。历史内容迁移及迁移异常处理由工程人员在上线前完成，不属于后台功能或后台用户权限。

### 5.4 最终 L3 结构

L2-28“网站内容管理与发布”包含 6 个最终 L3：

| L3 编号 | L3 名称 | 主要业务结果 |
|---|---|---|
| L2-28-L3-01 | 网站栏目结构维护 | 形成主站和“中心党建”可用的栏目层级、展示位置和内容承载方式 |
| L2-28-L3-02 | 网站内容维护 | 维护本站文章、单篇内容、图片、附件、外部链接和嵌入内容 |
| L2-28-L3-03 | 网站内容发布管理 | 按草稿、已发布、已撤回状态控制公开内容的形成、撤回和重新发布 |
| L2-28-L3-04 | 首页轮播与推荐内容维护 | 组织主站和“中心党建”首页轮播、推荐内容、专题横幅及内容来源 |
| L2-28-L3-05 | 服务入口与网站导航维护 | 统一维护快捷服务入口、普通外部链接、网站导航和友情链接 |
| L2-28-L3-06 | 站点公共信息维护 | 维护网站标识、联系方式、备案、版权等可变公共信息 |

L2-29“网站展示与服务导航”包含 5 个最终 L3：

| L3 编号 | L3 名称 | 主要业务结果 |
|---|---|---|
| L2-29-L3-01 | 主站首页公开展示 | 面向公众展示主站首页的栏目内容、推荐内容和服务入口 |
| L2-29-L3-02 | 中心党建主题展示 | 在同一网站内以独立主题展示“中心党建”栏目内容 |
| L2-29-L3-03 | 公开内容浏览与分享 | 提供公开内容浏览、附件获取、链接复制和二维码分享 |
| L2-29-L3-04 | 第三方嵌入内容展示 | 在本站页面框架内展示第三方内容并提供必要的降级访问入口 |
| L2-29-L3-05 | 外部链接与业务入口导航 | 将公众导航至普通外部网站或目标业务系统 |

以上 11 个 L3 是 L1-06 第一阶段的最终浅层能力结构。页面类型、主题模板、响应式适配、文件存储、地址白名单、浏览量计数方式和基础搜索引擎收录实现均不单独形成 L3。

## 6. L2-28 网站内容管理与发布：栏目建设

### 6.1 初始化栏目结构

新网站以现网栏目作为初始化结构。主站主要包括：

| 一级栏目 | 主要二级栏目或内容 |
|---|---|
| 网站首页 | 首页综合信息展示 |
| 中心党建 | 高层声音、工作动态、学习园地等 |
| 招聘信息 | 在招职位、招聘简章、双选会、现场宣讲、留省就业 |
| 业务指南 | 就业派遣、档案管理、流动党员、学历认证、联系我们、常见问题 |
| 政策法规 | 就业创业政策宣传月、省外政策、省内政策、国家政策 |
| 就业指导 | 直播课程、就业创业师资库 |
| 典型事迹 | 基层就业、创业、军营战士等典型事迹 |
| 预决算公开 | 预决算公开内容 |
| 关于我们 | 中心介绍、职责、服务项目和联系方式 |

现网栏目名称和层级应在迁移实施前再次核对。初始化后，管理员可以根据实际运营需要维护栏目结构。

### 6.2 栏目管理

后台支持：

- 新增、修改、排序和启停栏目；
- 维护一级栏目和多级子栏目；
- 配置栏目名称、展示位置和页面类型；
- 将栏目配置为内容列表、单篇内容、外部链接或嵌入页面；
- 分别维护主站导航和“中心党建”子栏目；
- 设置栏目对应的主题及页面模板。

已有内容的栏目不得直接删除。需要调整时，应先处理其下属栏目和内容，避免历史内容失去归属。

## 7. L2-29 网站展示与服务导航：前台功能

### 7.1 主站首页公开展示

主站首页延续现网主要信息结构，可包括：

1. 顶部平台标识及学生入口；
2. 网站名称和主题横幅；
3. 主导航及下拉二级菜单；
4. 图片轮播；
5. 通知公告；
6. 常用业务入口；
7. 招聘日历；
8. 就业动态；
9. 业务指南快捷导航；
10. 专题宣传横幅；
11. 最新招聘；
12. 直播课程；
13. 招聘公告；
14. 国家大学生就业服务平台及相关外部入口；
15. 分类网站导航和友情链接；
16. 地址、电话、办公时间、备案及版权等页脚信息。

具体首页区域、名称和排列可以在原型设计阶段结合现网内容进行现代化调整，但不得改变已经确认的栏目和业务入口边界。

### 7.2 中心党建主题展示

“中心党建”首页使用独立红色主题，主要呈现：

- 党建图片轮播；
- 高层声音；
- 工作动态；
- 学习园地；
- 党章党规；
- 理论学习。

后台可分别配置党建首页的轮播、内容来源、推荐内容、显示数量和跳转位置。

主站首页公开展示与“中心党建”主题展示是两个独立 L3，但仍属于同一网站，使用同一后台和同一内容模型，不据此拆分 L2、网站或部署系统。

### 7.3 公共页面类型

前台至少支持以下页面类型：

| 页面类型 | 功能要求 |
|---|---|
| 栏目首页 | 展示栏目主题、轮播、内容摘要、推荐内容和快捷入口 |
| 内容列表页 | 展示面包屑、栏目名称、标题、发布日期和分页 |
| 内容详情页 | 展示标题、来源、发布日期、正文、图片、附件和分享入口 |
| 单篇内容页 | 展示中心介绍、联系我们、业务指南等相对固定内容 |
| 分类或标签页 | 在同一专题内切换相关子栏目 |
| iframe 聚合页 | 保留本站页面框架并嵌入第三方页面 |
| 外部链接页 | 直接跳转到外部网站或外部业务系统 |

### 7.4 公开内容浏览与分享

已发布内容应具有可直接访问的独立地址，并满足：

- 浏览器前进、后退和刷新行为正常；
- 复制的内容地址能够直接打开对应页面；
- 已撤回、已删除或不存在的内容显示统一提示；
- 外部链接原则上在新窗口打开；
- 附件显示名称并提供下载入口；
- 页面支持复制当前链接，可生成访问二维码；
- 不直接集成微信、微博等第三方分享接口。

公开内容的本站查找方式仅包括首页推荐、栏目导航和内容列表。独立内容地址用于直接访问、浏览器刷新与前进后退、复制链接、二维码分享和基础搜索引擎收录，不作为本站内容查找方式。第一阶段不建设站内全文搜索。

外部链接和业务入口只负责导航。目标系统中的身份认证、站内搜索、查询和业务办理仍由目标系统负责，不属于本 L2。

## 8. L2-28 网站内容管理与发布：内容管理

### 8.1 内容形式

后台统一支持：

1. 本站文章；
2. 外部链接；
3. 单篇内容；
4. 图片或专题入口；
5. iframe 嵌入内容。

外部链接和 iframe 地址只能由具备相应后台权限的用户配置。地址白名单、内容安全策略等实现细节在设计阶段确定。

### 8.2 文章信息

本站文章支持：

- 标题；
- 所属栏目；
- 富文本正文；
- 内容来源；
- 发布日期；
- 封面图片或列表缩略图；
- 一个或多个附件；
- 是否置顶；
- 是否推荐；
- 展示顺序；
- 内容状态；
- 实际发布时间；
- 最后修改时间；
- 浏览量。

发布日期允许后台用户设置，以满足历史迁移和内容补录需要。前台主要展示发布日期，不强调录入时间。

新建内容首先形成草稿。修改已有内容只更新内容本身，不自动改变其发布状态；内容是否进入或退出公众可访问范围由网站内容发布管理统一控制。

### 8.3 网站内容发布管理

第一阶段采用简化发布流程：

```text
草稿 → 已发布 → 已撤回 → 已发布
```

具备发布权限的用户可以直接发布内容，不建设“编辑提交—领导审核—正式发布”的多级审核流程。

内容状态包括：

- 草稿；
- 已发布；
- 已撤回。

### 8.4 图片与附件

系统支持：

- 在富文本正文中上传和插入图片；
- 为一篇文章上传多个附件；
- 为轮播图、专题横幅和快捷入口分别上传展示图片；
- 保存和使用文章、轮播、横幅及入口所需图片和附件。

第一阶段不建设独立、面向后台用户的公共素材库，图片和附件在维护相关内容时上传和选择。

统一文件存储是后续设计依赖，不作为 L1-06 的业务输入输出提供方；存储方式、容量、安全和备份要求在系统设计与非功能设计中确定。

## 9. L2-28 网站内容管理与发布：首页与展示内容管理

### 9.1 首页内容组织

首页采用“栏目关联为主、人工推荐为辅”的方式：

- 通知公告、就业动态等区域默认展示关联栏目的最新已发布内容；
- 轮播图、专题横幅和快捷入口单独维护；
- 重要文章可以设置推荐、置顶和展示顺序；
- 每个内容区域可以配置显示数量、栏目来源和“更多”跳转位置；
- 主站首页和“中心党建”首页分别配置内容，但使用相同的后台管理机制。

首页运营能力只组织既有栏目和内容来源，不取得来源内容所有权，也不改变来源内容的发布状态。

### 9.2 服务入口与网站导航维护

快捷服务入口、普通外部链接、网站导航和友情链接统一归入本 L3。不同展示位置可以分别组织，但不拆成独立能力。服务入口可维护名称、图片、链接地址、展示位置、排序和启停状态；网站导航可以按类别管理，例如：

- 相关网站服务；
- 各地毕业生就业网站；
- 吉林省高校联盟。

每个链接可维护名称、地址、排序和启停状态。系统不自动检测外部网站是否可访问。

### 9.3 站点公共信息维护

后台支持维护：

- 网站名称和标识；
- 顶部平台标识及相关链接；
- 地址、联系电话和办公时间；
- 备案号及备案链接；
- 页脚版权信息；
- 学生入口等全局快捷链接；
- 主站和“中心党建”的主题横幅、标识及基础展示信息。

仅对可能变化的公共内容提供配置，不建设通用可视化页面设计器。

## 10. L2-29 网站展示与服务导航：第三方嵌入内容展示

### 10.1 集成方式

第三方嵌入内容通过 iframe 在本站页面框架内展示。后台可配置：

- 标题；
- 嵌入地址；
- 展示位置；
- 展示尺寸；
- 启停状态；
- 原页面访问地址。

### 10.2 异常处理

第三方内容无法加载时：

- 只影响对应嵌入区域；
- 不影响网站其他栏目和本站内容；
- 前台显示统一的加载失败提示；
- 可以提供“打开原页面”入口；
- 手机端无法良好适配时可以直接显示外部链接入口。

本系统不缓存、同步或重试第三方内容，不对第三方内容自身的正确性、连续可用性和浏览器兼容性负责。

iframe 嵌入与普通外链或业务入口属于不同 L3。前者负责本站框架内的内容展示和降级访问，后者只负责导航至外部网站或目标业务系统。

## 11. L2-29 网站展示与服务导航：视觉与交互要求

### 11.1 视觉原则

新网站不要求像素级复制现网，采用“风格延续、布局现代化”的方式：

- 主站延续蓝—青色主题；
- “中心党建”延续红色主题；
- 保留现有横幅、内容分区和栏目识别特征；
- 优化字体、留白、卡片、层级和交互细节；
- 两套主题共享基础组件和整体品牌一致性。

### 11.2 响应式适配

前台应适配：

- 桌面浏览器；
- 平板设备；
- 手机浏览器。

移动端应支持导航折叠、内容列表重排、图片自适应和嵌入区域降级。页面不应继续依赖仅适用于桌面端的固定宽度布局。

### 11.3 浏览器兼容

第一阶段重点支持：

- Chrome；
- Edge；
- Android 主流浏览器；
- 微信内置浏览器；
- iPhone Safari；
- Firefox 作为一般兼容目标。

不兼容 Internet Explorer，不为已停止维护的旧版浏览器单独开发降级页面。

## 12. L2-29 网站展示与服务导航：浏览量与公开访问支持

### 12.1 浏览量

系统记录文章浏览量，并允许后台查看文章访问次数。第一阶段不建设独立流量分析、用户画像、访问来源分析或复杂统计报表。

如需网站整体访问分析，可在实施阶段接入已有第三方统计服务，但不作为信息发布后台核心功能。

### 12.2 基础搜索引擎收录

已发布文章应具备基础搜索引擎友好能力，包括：

- 合理的页面标题和摘要；
- 清晰、稳定的内容地址；
- 可直接访问和分享的页面；
- 允许公开内容被搜索引擎正常收录。

第一阶段不建设复杂 SEO 运营、关键词管理和收录效果分析。

### 12.3 本站内容查找边界

第一阶段不建设站内全文搜索。用户仅通过首页推荐、栏目导航和内容列表查找本站内容；独立内容地址不作为本站内容查找方式。后续内容规模或客户检索需求发生变化时再单独规划。

## 13. L2-29 网站展示与服务导航：域名与历史地址兼容

### 13.1 公开访问入口

`www.jilinjobs.cn` 继续作为公开访问入口。当前实际运行域名和最终确定的新域名根据部署方案设置跳转或兼容访问，均指向同一信息发布网站。

### 13.2 历史地址

迁移本站文章时，应尽量保留旧内容与新内容的对应关系：

- 对能够明确匹配的旧详情地址设置跳转；
- 不要求新系统完全沿用旧网站页面路径和技术参数；
- `cms.jilinjobs.cn` 等历史地址仅对能够明确匹配的内容提供兼容；
- 第三方 iframe 和外部链接不纳入旧网址兼容范围。

具体域名解析、证书、代理和重定向规则在部署设计阶段确定。

## 14. 历史内容迁移

### 14.1 迁移范围

上线前整体迁移原网站自身发布的内容，包括：

- 栏目及层级关系；
- 文章标题；
- 富文本正文；
- 内容来源；
- 发布日期；
- 正文图片；
- 封面图片；
- 附件；
- 外部链接；
- 可识别的旧内容地址对应关系。

慧就业等第三方嵌入内容不迁移。

### 14.2 实施方式

历史内容迁移由工程人员在上线前手工或使用专项迁移工具完成。迁移功能、迁移异常处理和异常修复不建设为日常后台能力。

### 14.3 迁移验收

迁移验收至少检查：

1. 栏目层级和内容归属正确；
2. 文章标题、正文、来源和发布日期完整；
3. 正文图片和封面能够正常显示；
4. 附件能够正常下载；
5. 外部链接能够正确跳转；
6. 可识别的历史文章地址能够跳转至新内容；
7. 第三方嵌入数据不计入迁移数量；
8. 原站已经缺失、损坏或无法访问的内容形成异常清单。

原站数据本身已经缺失或损坏时，不要求新系统自动修复。

## 15. 原型建设要求

需求定稿后建设一套可运行的高保真前台原型，至少覆盖：

- 主站首页；
- “中心党建”红色主题首页；
- 内容列表页；
- 内容详情页；
- 单篇内容页；
- 第三方 iframe 聚合页；
- 手机端主要页面；
- 导航、轮播、栏目切换和响应式布局等基本交互。

原型用于确认新网站视觉框架、信息结构和交互方向，不直接作为生产系统交付物。第一阶段不制作完整后台高保真原型，后台页面在功能设计和开发阶段按照统一管理端规范实现。

## 16. 跨模块关系

### 16.1 与智慧就业云平台业务系统

网站展示与服务导航负责展示和跳转，不负责学生身份认证、就业信息填报、档案办理、党员办理等业务。相关入口跳转至对应业务系统后，由目标模块执行认证、授权和业务处理。

### 16.2 与平台身份与治理

后台复用管理端账号与认证、角色与权限管理和组织机构管理提供的中心账号、菜单授权和数据范围能力。网站内容管理与发布只定义栏目、内容、发布和站点配置等业务权限，不重复建设账号体系。

### 16.3 与文件存储设计

文章图片、封面和附件需要文件存储支撑。该支撑属于设计依赖，不作为其他业务 L2 向本模块提供的业务输入或输出；文件安全、容量、备份等技术要求在系统设计和非功能设计中统一确定。

### 16.4 与微信公众号

微信公众号自身的信息发布和菜单维护由微信平台承担。网站展示与服务导航可提供供公众号菜单跳转的公开页面和业务入口，但不建设微信公众号运营后台。

## 17. 完整性与一致性复核结论

本需求已从网站组成、栏目建设、前台页面、内容管理、首页配置、用户权限、第三方集成、视觉主题、移动端、浏览器兼容、内容迁移、历史地址、访问统计、搜索引擎和原型范围等方面完成复核。

复核结论如下：

1. “中心党建”在内容呈现上相对独立，但业务和技术定位是主站中的独立一级栏目，不是独立部署的子网站；
2. 主站和“中心党建”分别使用蓝—青色与红色主题，但共用一套后台、接口服务、账号权限和内容管理机制；
3. 慧就业招聘等第三方内容只做 iframe 或外部链接集成，与本站文章发布及历史迁移边界清晰；
4. 前台公开访问与后台统一账号管理不存在角色冲突；
5. 简化发布流程与栏目权限配合使用，第一阶段不需要多级审核流程；
6. 历史内容迁移由工程人员在上线前完成，不错误纳入后台功能或用户权限；
7. 网站业务入口只承担展示和跳转，不重复建设学生端、档案管理、党员管理等业务能力；
8. 移动端适配、主流浏览器兼容、基础搜索引擎友好和内容可访问性要求与现网功能复刻目标一致；
9. 第一阶段不建设全文搜索、互动功能、复杂统计和完整后台原型，范围与网站现有内容规模相匹配；
10. 内容浏览量记录和后台查看继续保留，但不形成独立 L3；
11. L1-06 不保留端到端业务流程候选，后台发布内容与前台只读消费是模块依赖，不抽取为端到端业务流程；
12. 当前不存在阻碍后续原型设计和功能设计的未确认业务问题。

## 18. 验收要点

第一阶段业务验收至少覆盖：

- 现网主要栏目已按确认结构初始化；
- 主站和“中心党建”主题、首页及内容页面能够正确区分；
- 栏目、文章、单篇内容、外部链接、图片入口和 iframe 内容可以维护；
- 草稿、发布、撤回和重新发布流程正确；
- 栏目权限和发布权限生效；
- 首页栏目关联、推荐、置顶、排序和展示数量符合配置；
- 图片、附件、轮播、专题横幅和快捷入口正常展示；
- 第三方内容加载失败不影响本站其他区域，并提供合理降级入口；
- 桌面端、平板和手机端主要页面可正常使用；
- 公开内容无需登录即可访问，业务入口可正确跳转；

- 本站内容只能通过首页推荐、栏目导航和内容列表查找，不提供站内全文搜索；
- 高保真前台原型覆盖已确认的主要页面和交互。
