# CMS 管理端规格说明（Specification）

## 1. 目标

本文定义独立 CMS 管理端的 WHAT / WHY。共享业务模型以 `docs/specifications/cms-core.md` 为准；公开站展示规则以 `docs/specifications/public-site.md` 为准。

管理端目标是提供通用、可复用的 CMS 管理体验，而不是把当前首页每个视觉区块都做成专用配置页面。

## 2. 管理信息架构

当前管理端至少提供：

- 文章管理；
- 栏目管理；
- 导航管理；
- 固定页面 / 页面组；
- 列表管理；
- 宣传展示管理；
- 网站属性；
- 静态资源。

管理端保持独立 `/admin/` SPA 和统一 Application Shell。技术路由 `/advertisements` 可以继续保留，产品界面统一显示“宣传展示”。

## 3. 导航管理

导航页面必须先选择导航位置，再管理该位置下的树形导航条目。主数据表只显示当前位置的数据，不再把 `position=MAIN` 作为每行重复字段展示。

推荐交互为左侧导航位置列表 + 右侧树形 Table。导航位置列表采用整行选择、选中高亮和右侧 `...` 编辑/删除菜单；数据模型不得依赖前端 Tab 常量。

导航位置允许当前阶段直接新增、修改、删除；导航条目支持树形新增/编辑/删除、目标对象、打开方式、可选图标、排序、启停。父级候选只显示当前导航位置内条目。

导航图标编辑复用统一图片资源选择器，可以从站点已整理的导航图标目录中选择，也可以上传自定义图标。图标是条目自身属性，不由排序位置推导。管理端对透明图标启用自适应预览背景：根据有效像素明暗自动选择深色、浅色或中性棋盘背景，并允许悬停切换对比背景；该行为仅用于后台可见性辅助，不改变图标文件和公开站页面背景。

## 4. 通用列表管理

列表管理允许维护列表定义及列表项。列表定义不控制公开页面的视觉展示模式，也不再通过 `itemType` 将字段绑定为 LINK / IMAGE_LINK / TEXT 套餐。

列表项统一提供标题、副标题、图片、目标地址、打开方式、排序、启停等数据属性。标题作为后台识别名称保留；图片和目标地址独立可选。具体页面是否使用标题、Logo、图片、链接以及如何组合展示，由公开站页面设计决定。

图片字段复用统一图片资源选择器，新图片上传到 `/static/uploads/lists/{listCode}/`，也可从 `/static/uploads/**` 共享 Runtime 图片库复用已有图片。

当前首页轮播和网站导航/友情链接通过此通用入口维护，不建立首页专用“轮播配置 JSON”。

## 5. 宣传展示管理

宣传展示管理允许维护展示位和展示内容。展示内容至少支持图片、可选链接、点击行为、展示顺序、启停和可选有效时间。

同一展示位可维护多条内容；`NO_LINK` 可以保留 URL 但临时禁止点击。图片字段复用统一图片资源选择器，新图片上传进入 `/static/uploads/displays/{slotCode}/`，并允许选择共享 Runtime 图片。

首页招聘活动横幅通过 `HOME_RECRUITMENT_PROMO` 展示位维护。

## 6. 网站属性

“网站配置”收敛为“网站属性”。管理端显示属性名称、key、分组、类型和值，并允许新增、编辑、删除属性定义。

类型化编辑和校验至少覆盖 TEXT、RESOURCE_PATH、JSON、URL、BOOLEAN。JSON 保存前执行真实解析；RESOURCE_PATH 使用 `/static/**`，并复用统一图片资源选择器，新图片上传到 `/static/uploads/site-properties/{key}/`，也可选择共享 Runtime 图片；URL 使用站内路径或 HTTP(S) 规则。

当前阶段不根据用户身份隐藏新增/删除按钮，也不实现普通管理员/超级管理员差异。相关限制只作为未来权限规划。

## 7. 统一图片资源选择

宣传展示、列表项、导航图标和 RESOURCE_PATH 网站属性等 CMS 图片字段复用同一图片选择与上传交互。控件至少支持当前图片预览、上传新图片、从 `/static/uploads/**` 共享 Runtime 图片库选择已有图片，并在导航等场景提供经过整理的内置图片候选。

新上传文件始终进入当前业务上下文约定目录；跨模块选择只复用已有资源，不改变上传目录治理。业务表单上传成功后保存 `/static/**` 路径；文件真实内容仍由 Backend StaticResource 统一校验。表单改变引用不得自动物理删除旧文件，未被引用资源由静态资源管理入口统一清理。

普通照片、Banner 等默认使用常规预览背景；只有图标等透明、小型视觉资源按使用场景显式开启自适应背景，避免将后台预览算法扩散为公开页面展示规则。

## 8. 风险操作

删除、关键资源替换等继续提供确认和业务保护。此类保护属于运行安全，不依赖认证授权。

静态资源继续提示“不提供完整引用检查”。不得开放任意 HTML/JavaScript 上传执行能力。

## 9. Acceptance Criteria

- 管理端导航入口包含列表、宣传展示、网站属性；
- 导航管理按位置 + 树形结构呈现，左侧位置操作体验与列表/展示位一致；
- 导航位置能够作为数据维护，导航图标能够作为条目属性维护；
- 透明浅色导航图标在管理端表格、当前值预览和内置图标库中均能够通过自适应背景清晰展示，且不影响公开站视觉；
- 通用列表不再暴露 `itemType`，列表项图片和 URL 独立可选；
- 宣传展示管理可维护首页招聘活动横幅并支持多内容/NO_LINK/有效期；
- 列表、宣传展示、导航图标、RESOURCE_PATH 属性复用统一图片资源选择/上传，并可跨 CMS 模块复用 Runtime 已上传图片；
- 网站属性可维护定义和值并进行类型校验；
- 当前阶段无登录/角色/权限实现；
- 既有文章、栏目、页面、静态资源管理能力无回归；
- Browser E2E 覆盖导航图标自适应预览、列表图片上传、共享图片复用、宣传展示和网站属性核心路径。
