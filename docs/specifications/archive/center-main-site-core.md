# 中心主站站点收敛规格说明（Specification）

## 1. 目标

本规格描述 2026-08-27 人工确认后的中心主站当前迭代 WHAT / WHY。

当前迭代在既有栏目、导航、文章、发布和公开页面原型基础上，把网站收敛到能够继续人工评审的真实主站形态：

- 以原网站视觉与布局为复刻基准；
- 建立固定页面与页面组；
- 建立稳定、分层公开 URL；
- 建立网站配置与网站静态资源管理；
- 形成站点初始化数据和静态资源基线；
- 保留招聘信息/直播课程外部嵌入页面框架，但本轮不接入真实 iframe；
- 保留中心党建主导航占位，但本轮不建设党建主题。

本规格不规定具体数据库字段、Nginx 语法、源码目录或逐文件实现步骤。

## 2. Authority

依据：

1. `AGENTS.md`
2. `README.md`
3. `docs/requirements/information-publishing.md` V4.0

当旧 Specification 或旧实现与 V4.0 冲突时，以当前 Requirement 为准。

## 3. Scope

### 3.1 In Scope

- 普通栏目 alias 与公开栏目 URL；
- 普通文章 canonical URL；
- 固定页面；
- 页面组；
- 业务指南页面组；
- 招聘信息页面组框架/占位；
- 直播课程占位入口；
- 主导航及二级菜单的真实初始化结构；
- 菜单目标类型及打开方式；
- 固定首页模板；
- 网站配置管理；
- 网站静态资源管理；
- 初始化数据库基线；
- 初始化静态资源包；
- 现网视觉/布局复刻；
- 普通栏目页、文章详情页、固定页面、页面组模板；
- 既有文章发布、附件、浏览量与公开状态能力继续有效。

### 3.2 Out of Scope

- 中心党建主题和内容实现；
- 真实慧就业 iframe；
- 认证授权实现；
- 通用 Page Builder；
- 通用静态资源引用图；
- 后台任意 HTML/JS 上传执行；
- 历史内容全量迁移程序本身；
- SSR/SSG；
- MQ/Redis/MinIO。

## 4. Required Behaviors

### 4.1 栏目与文章 URL

- 栏目具有稳定 alias。
- 栏目公开地址为 `/column/{alias}`。
- 文章公开地址为 `/article/{id}`。
- 栏目层级和面包屑不从文章 URL 推导。
- 同一文章只有一个 canonical URL。
- 已有文章状态和公开过滤规则保持不变。

### 4.2 固定页面

后台可以维护固定页面：管理名称、alias、页面组（可空）、正文、展示方式、排序、启停状态。

普通固定页地址 `/page/{alias}`，页面组成员地址 `/page/{groupAlias}/{alias}`。

普通固定页不显示普通文章的来源、发布时间、浏览量信息区。

### 4.3 页面组

后台可以维护页面组及成员顺序。页面组成员在前台共享公共 Tab、当前成员高亮、页面组上下文和统一页面框架。

公共 Tab 必须来自页面组成员数据，不在前端硬编码。

### 4.4 业务指南

初始化 `guide` 页面组，至少保证：

```text
/page/guide/jypq
/page/guide/dagl
/page/guide/dygl
/page/guide/xlrz
```

并提供“联系我们”“常见问题”成员。

业务指南默认可以使用通用 Page Shell；具体页面出现独立渲染需求时允许增量增加专用 Shell，而不改变 URL。

### 4.5 招聘信息

初始化 `jobs` 页面组：在招职位、招聘简章、双选会、现场宣讲、留省就业。

成员使用 `/page/jobs/{alias}`。本轮显示完整本站页面框架、公共 Tab 和明确占位内容，不加载真实慧就业 iframe。

### 4.6 直播课程

保留“就业指导 → 直播课程”入口及稳定本站页面身份。本轮使用外部嵌入占位展示，不加载真实外部内容。

### 4.7 菜单

菜单目标至少支持 HOME、COLUMN、PAGE、LINK、PLACEHOLDER。

本站对象目标优先保存业务对象关系；外部链接保存 URL。

默认打开方式：外部 URL → 新窗口；其他本站目标 → 当前窗口；后台允许显式覆盖。

主导航和二级菜单应按 Requirement V4.0 初始化。

### 4.8 首页

首页采用固定模板，不提供通用拖拽编排。

首页使用真实菜单、栏目/文章数据、网站配置和静态资源；保留外部内容区域占位；不复制文章形成首页专属内容副本。

现网主要区域和相对顺序作为第一版实现基准。

### 4.9 网站配置

后台提供预定义的网站配置项，而不是任意 Key-Value 配置中心。

至少允许维护网站名称、Logo 资源路径、页脚公共信息、联系方式、固定业务入口、Banner、网站导航/友情链接组。

### 4.10 网站静态资源

后台提供高风险静态资源管理入口，第一版支持浏览目录/文件、上传、替换、查看/下载、删除到回收区、恢复。

管理对象以指定静态目录的实际文件为事实来源，因此直接手工放入该目录的文件也能被后台看到。

第一版不做完整资源引用分析。删除/替换时必须提示可能破坏现有页面引用。

### 4.11 初始化基线

干净数据库执行 Flyway 后应形成真实站点骨架：栏目、菜单、页面组、固定页面、网站配置。

初始化静态资源包与数据库基线共同定义完整站点初始状态。自动化测试不再负责创建这些基础结构。

### 4.12 视觉复刻

首页、栏目列表、文章详情、普通固定页面、业务指南页面组优先复刻原网站蓝—青色视觉、Header / Logo / 主导航 / Footer、首页主要区块关系和内容页面主要版式。

允许必要响应式和兼容性调整，不主动重新设计成与原站明显不同的现代化门户。

## 5. Business Rules

1. 菜单结构与栏目结构分离。
2. 页面组不是普通栏目。
3. URL 表达稳定页面身份，但不作为面包屑唯一事实来源。
4. 首页只是组合展示，不取得文章所有权。
5. 固定页面 alias 稳定；变更属于高影响操作。
6. 页面组成员 Tab 由数据生成。
7. 外部嵌入是呈现能力，不等同于页面组业务归属。
8. 站内特殊静态页面属于工程资产，不允许 CMS 用户任意上传执行。
9. 网站静态资源不承诺完整引用检测。
10. 站点初始化基线与测试数据、历史迁移数据分离。
11. 已发布内容公开、草稿/撤回隐藏的既有规则继续生效。
12. 高风险网站配置和静态资源操作必须保留独立权限边界。

## 6. Boundary / Failure Behavior

- alias 冲突时拒绝保存。
- 页面组不存在或停用时，其成员不作为正常公开页面展示。
- 固定页面不存在/停用时返回统一不可用结果。
- 外部嵌入占位页不得假装第三方内容已接入。
- 静态资源删除进入回收区，不默认立即永久删除。
- 静态资源操作明确提示系统不做完整引用检查。
- 访问不存在的 `/page/**`、`/column/**`、`/article/**` 返回明确不存在页面。
- 初始化 migration 必须可重复应用到干净环境，不依赖 Playwright 造基础数据。

## 7. Relevant Non-functional Constraints

- 公开页面可直接访问、刷新、复制和前进后退。
- URL 与具体 HTML Entry 解耦，允许多 Shell 演进。
- 第一版不要求立即拆出 guide/jobs 专用 HTML Entry，但架构不得阻止以后按 URL 层级增加专用 Shell。
- 当前保持 Vue 3 + TypeScript + Vite。
- 后端保持 Spring Boot + Kotlin + MyBatis + MySQL。
- 当前不引入 MQ/Redis/MinIO。
- 静态资源文件名和相对路径必须防止目录穿越。
- 公开站点继续满足当前目标浏览器和响应式要求。

## 8. Acceptance Criteria

本迭代完成时，应以 Current Evidence 证明：

1. Flyway 在干净 MySQL 中建立新数据结构和站点初始化基线。
2. 主菜单显示确认后的现网结构，无“空中宣讲”。
3. 中心党建为占位，不渲染未实现的党建主题内容。
4. `/column/{alias}` 可访问普通栏目。
5. `/article/{id}` 可访问已发布文章。
6. `/page/about` 等普通固定页可访问。
7. `guide` 页面组公共 Tab 数据驱动并支持至少四个确认 URL。
8. `jobs` 页面组存在 5 个确认成员并显示外部内容占位。
9. 直播课程保留占位入口。
10. 菜单可以绑定栏目、页面、链接、占位目标，打开方式规则正确。
11. 网站配置后台能够维护预定义站点级配置。
12. 网站静态资源后台能够列出实际目录文件、上传、替换、删除到回收区和恢复。
13. 普通文章资源能力没有被静态资源管理破坏。
14. 首页主要布局和视觉相较旧原型明显收敛到现网基准。
15. 栏目列表、文章详情、普通固定页、业务指南均有对应前台模板。
16. 后端自动化测试通过。
17. 前端类型检查和 Vite build 通过。
18. Playwright 至少验证初始化基线、主导航、固定页、业务指南、招聘占位和文章公开主路径。
