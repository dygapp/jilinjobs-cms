# Current 文档中文主语言

面向人的 Current / Partially Current 文档以中文为主述，必要时保留英文精确锚点。代码标识符、路径、命令、API、协议、枚举值和固定技术专名保持原生形式。

语言调整不得改变 Product Goal、Scope、Business Boundary、User-visible Behavior、Architecture Decision 或技术契约。历史证据以证据保真优先；重新晋升为 Current Authority 前再满足当前语言规范。
